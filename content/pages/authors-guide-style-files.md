## Style Files

The main PDF file should be created in LaTeX using the RLJ style files. Submissions that
do not use them, or that violate the formatting instructions in the
[Authors Guide](/authors-guide#formatting-instructions), may be rejected without further
review.

See the contents of the template for additional instructions on preparing the PDF file.
Authors are not required to use Overleaf to prepare their submission: the zip archive
above contains the same files. From Overleaf itself, the LaTeX source can be downloaded
by clicking the "Menu" button in the top-right, then selecting the "Source" icon near the
top of the menu that appears.

## Final Version

Accepted papers are prepared with the `[accept]` option in the same style files. See
[Preparing the Final Version](/authors-guide#preparing-the-final-version).

## Forms

Accepted papers require a signed
[Publication Agreement](https://rlj.cs.umass.edu/RLC_Publication_Agreement_Form.pdf),
which acknowledges the rights granted to the journal.
